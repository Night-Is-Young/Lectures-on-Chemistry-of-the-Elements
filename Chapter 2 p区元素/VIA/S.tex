\subsubsection{\ce{S8}: $\alpha$-正交硫, $\beta$-单斜硫和$\gamma$-单斜硫}
硫最常见的,也是热力学上最稳定的单质为正交$\mbf{\alpha}$-\ce{S8}(简称\tbf{正交硫}).这是一种黄色固体,具有优良的绝缘性和绝热性.正交硫中含有$D_{4\text{d}}$点群的~\ce{S8}分子,其结构颇像皇冠.

加热$\alpha$-\ce{S8}至$\SI{95.3}{\celsius}$可使其转变为$\beta$-单斜~\ce{S8}.将硫熔融后缓慢冷却可以得到$\gamma$-单斜~\ce{S8},这种相在自然界中非常少见.上述两种晶型都由~\ce{S8}分子组成,区别只在于排列方式不同.
\subsubsection{\ce{S6}: $\ep$-硫}
$\ep$-硫由~\ce{S6}分子构成,其颜色为橙红色,分子构象与环己烷的椅式六元环一致.这种同素异形体可以由下面的反应制得:
\begin{tightcenter}
    \ce{H2S4 + S2Cl2 ->T[\ce{Et2O}] S6 + 2HCl}
\end{tightcenter}
\subsubsection{\ce{S}的小分子:~\ce{S2}与~\ce{S3}}
低压高温的硫蒸汽中存在~\ce{S2}与~\ce{S3}分子.~\ce{S3}分子呈现樱桃红色,结构与~\ce{O3}类似.~\ce{S2}分子呈现紫色,结构与~\ce{O2}类似.
\subsection{硫的氢化物和金属硫化物}
\subsubsection{\ce{H2S}}
硫化氢,化学式为~\ce{H2S},是无色的具有臭鸡蛋味的剧毒气体.
\paragraph{\ce{H2S}的毒性}
低浓度的~\ce{H2S}会令人闻到恶臭的刺激性气味,对眼,呼吸系统和神经系统都有影响;而高浓度的~\ce{H2S}则会迅速麻痹人的嗅觉,并可在短时间内致命,因此更加危险.
\paragraph{\ce{H2S}的化学性质}
\ce{H2S}是易燃气体,在空气中燃烧时发出浅蓝色的火焰:
\begin{tightcenter}
    \ce{2H2S + 3O2 ->[\text{燃烧}] 2H2O + 2SO2}
\end{tightcenter}
\indent \ce{H2S}易溶于水,室温下在纯水中的溶解度\footnote{一般而言,气体的溶解度仅指该形态的饱和浓度,这与分析浓度是不同的.对于\ce{H2S}而言,饱和时其浓度总是为$0.1\text{ mol}\cdot\text{L}^{-1}$,与\ce{HS-}或\ce{S^2-}的浓度无关.}大约为$0.1\text{ mol}\cdot\text{L}^{-1}$.~\ce{H2S}在水溶液中是较弱的酸:
\begin{tightcenter}
    \ce{H2S <=> HS- + H+}\quad$\text{p}K_{a1}=7.04$\\
    \ce{HS- <=> S^2- + H+}\quad$\text{p}K_{a2}=19$
\end{tightcenter}
\indent \ce{H2S}也是一种中等强度的还原剂.将~\ce{H2S}溶液置于空气中,溶液将缓慢地变浑浊,其中生成了~\ce{S}单质沉淀(一般而言,书写产生~\ce{S}单质的反应方程式时,不必特意指出其为~\ce{S8},除非有特别的要求):
\begin{tightcenter}
    \ce{2H2S + O2 -> 2H2O + 2S}
\end{tightcenter}
也可以和~\ce{SO2}发生归中反应生成~\ce{S}单质:
\begin{tightcenter}
    \ce{2H2S + SO2 -> 2H2O + 3S}
\end{tightcenter}
\paragraph{\ce{H2S}的制备}
由于~\ce{H2S}的酸性很弱,因此可以用金属硫化物的水解或酸解反应制备~\ce{H2S}:
\begin{tightcenter}
    \ce{FeS + 2HCl -> FeCl2 + H2O}\\
    \ce{Al2S3 + 6H2O -> 3H2S + 2Al(OH)3}
\end{tightcenter}

自然界有许多重要矿物以及金属元素的矿石是硫化物,这些矿石最重要的用途是自其中冶炼出金属.这些矿物中比较重要的列举如下:

\subsection{多硫阴离子与阴离子自由基}
\subsubsection{多硫阴离子的制备与结构}
目前,人们已经制备并表征了$n=2\sim9$的所有多硫阴离子~\ce{S_n^2-}.在碱金属硫化物溶液和硫单质的混合体系中就可以得到~\ce{S_n^2-}$(n=2,3,4,5)$:
\begin{tightcenter}
    \ce{S^{2-} + n S -> S_{n+1}^{2-}}
\end{tightcenter}
这些离子的溶液为黄色,并且颜色随着$n$的增加而加深:~\ce{S_2^{2-}}为浅黄色,中等链长的~\ce{S_n^{2-}}为橙黄色,长链的~\ce{S_n^{2-}}为橙红色.\\
\indent 将~\ce{H2S}通入含有~\ce{S}单质的氨水溶液,然后加入合适的~\ce{[R4N]+}或~\ce{[P4N]+}等阳离子可以多硫阴离子结晶成盐.对于$n\geq5$的~\ce{S_n^{2-}},只能作为大而稳定的阳离子的盐而被分离为固相.高对称性的阳离子形成的盐(例如~\ce{[PPh4]2S7}\cite{Kanatzidis1983})中,~\ce{S_n^{2-}}通常为全反式螺旋构象,其中所有扭转角都是邻交叉的.\\
\indent 碱金属碳酸盐的水溶液或甲醇溶液在加热条件下也可以使~\ce{S}单质发生歧化而生成~\ce{S_n^{2-}}\cite{Sheldrick1997}:
\begin{tightcenter}
    \ce{3CO3^{2-} + $2(n+1)$ S -> 2S_n^{2-} + S2O3^{2-} + 3CO2}
\end{tightcenter}

\subsubsection{多硫阴离子的应用}
多硫离子可以用作病虫害防治,典型的例子是石灰硫磺合剂,简称\tbf{石硫合剂}.它是~\ce{Ca(OH)2}和~\ce{S}单质在水中熬制反应得到的暗褐色碱性液体,主要成分是~\ce{CaS_n}和~\ce{CaS2O3}.经过过滤后的石硫合剂是红黄色的溶液,通常需要稀释后喷洒在作物表面起到杀菌防虫的效果.石硫合剂具有强碱性,同时能释放~\ce{H2S},从而起到双重的杀菌效果.\\
\indent 多硫离子的另一个重要应用是锂硫电池和钠硫电池.由于硫的原子量相对适中,因此这种电池具有更高的能量密度和更低的成本.电池放电时,~\ce{S8}单质逐渐被还原为~\ce{S^{2-}}\cite{Lin2015}:
\begin{tightcenter}
    \ce{S8 -> [S8]^{2-} -> [S6]^{2-} -> [S4]^{2-} -> [S3]^{2-} -> [S2]^{2-} -> S^{2-}}
\end{tightcenter}
充电时则发生上述反应的逆过程.\\
\indent 多硫基团也经常出现在有机物中,例如硫化橡胶中交联各高分子链的多硫基团.含有多硫基团的一个有趣的小分子是\tbf{蘑菇香精(Lenthionine)},其分子结构如下所示,是香菇的主要风味物质之一\cite{Block1994}:

\subsubsection{多硫阴离子自由基}
早在150年前, Geitner就发现在含有微量碱的水溶液中加热硫单质可以得到蓝色溶液,但直到20世纪70年代人们才将这种蓝色的离子鉴定为\tbf{三硫自由基阴离子}~\ce{[S3]^{$\cdot$-}}.后来,人们发现在电子给体溶剂(例如~\ce{NH3}等)中~\ce{S6^{2-}}与~\ce{[S3]^{$\cdot$-}}存在解离平衡:
\begin{tightcenter}
    \ce{[S6]^{2-} <=> 2[S3]^{$\cdot$-}}
\end{tightcenter}
除~\ce{[S3]^{$\cdot$-}}之外,链状的多硫阴离子自由基包括黄色的~\ce{[S2]^{$\cdot$-}}和红色的~\ce{[S4]^{$\cdot$-}}.在硫单质存在的情况下,上述三者在溶液中可以互相转化.\\
\indent \ce{[S3]^{$\cdot$-}}可以被多种固体基质捕获而稳定存在.在这类化合物中最著名的是天然矿物\tbf{青金石},其中~\ce{[S2]^{$\cdot$-}}和~\ce{[S3]^{$\cdot$-}}替代了方钠石~\ce{Na8[Al6Si6O24]Cl2}中部分~\ce{Cl-}的位置,从而显现鲜艳的蓝色;并且由于铝硅酸盐骨架的阻隔而使得这些自由基得到稳定.青金石在古代美索不达米亚和埃及文明中有非常重要的地位:在\textit{Epic of Gilgamesh}\footnote{即美索不达米亚的著名英雄史诗《吉尔伽美什史诗》,是已发现的最早的英雄史诗.}中,英雄的伟大事迹就记录在青金石板上;青金石也作为饰品镶嵌在Tutankhamen的死亡面具上.\\
\indent 青金石提纯后即可得到著名的蓝色颜料\tbf{群青}.群青在古代是名贵颜料,而在1826年, J.B.Guimet首次实现了群青的工业合成.他用高岭土,碳酸钠,硫和硫酸钠混合体系加热制备群青的方法,得到了价格便宜且色彩更鲜艳的人工群青颜料.通过调节反应物比例而改变产物中~\ce{[S2]^{$\cdot$-}}和~\ce{[S3]^{$\cdot$-}}的比例,还可以制备绿色到蓝色到粉色等一系列人造群青颜料.\\
\indent 然而,目前制备的能在固相中独立存在的多硫自由基阴离子只有环状的~\ce{[S6]^{$\cdot$-}},存在于~\ce{[Ph4P]S6}中.它可以按照下面的反应制备\cite{Bernhard2000}:
\begin{tightcenter}
    \ce{2[Ph4P]N3 + 20TMSN3 + 22H2S -> 2[Ph4P]S6 + 10TMS2S + 11NH4N3 + 11N2}
\end{tightcenter}
\ce{[S6]^{$\cdot$-}}可以视作由~\ce{[S3]^{$\cdot$-}}离子和~\ce{S3}分子缔合而成,两者发生$\pi$轨道的重新组合并形成一个较弱的相互作用,如下图所示:

\subsection{硫的氧化物}
\subsubsection{二氧化硫\ce{SO2}}
二氧化硫,化学式为~\ce{SO2},是无色,有窒息性臭味的有毒气体,是硫的常见氧化物之一.~\ce{SO2}的熔点为$\SI{-75.5}{\celsius}$,沸点为$\SI{-10.0}{\celsius}$.~\ce{SO2}气体易溶于水,并且形成亚硫酸水溶液.\\
\indent 工业上大规模制备~\ce{SO2}是由硫或~\ce{H2S}在空气中燃烧(见~\ce{H2S}的相关反应),或锻烧黄铁矿:
\begin{tightcenter}
    \ce{4FeS2 + 11O2 -> 2Fe2O3 + 8SO2}
\end{tightcenter}
由于黄铁矿含硒,砷等杂质较多,这种方法的占比已经逐渐下降.\\
\indent \ce{SO2}也是一种常见的大气污染物\cite{GB26132-2010}(在这份标准的编制说明中也详细介绍了生产~\ce{SO2}的过程中可能产生的各种污染物以及处理方法).工业上生产的~\ce{SO2}主要用来制备硫酸;其他的应用有漂白,杀菌,食物保存,冷冻或作为非水溶剂等.

\indent $\gamma$-\ce{SO3}和$\beta$-\ce{SO3}都是亚稳态的,在痕量水的作用下就会缓慢地转变为$\alpha$-\ce{SO3}.同一温度下这三种晶型的蒸气压大小顺序为$\alpha<\beta<\gamma$,而液态~\ce{SO3}由~\ce{S3O9}分子构成,对应于$\gamma$相.因此,加热$\alpha$-\ce{SO3}至熔化时会导致其蒸气压突然升高,巨大的压力可以冲破加热它的玻璃管.这一现象称为$\symbf\alpha$\tbf{爆炸}.\\
\indent 工业上制备~\ce{SO3}通常在催化剂(例如~\ce{V2O5})的存在下氧化~\ce{SO2}得到:
\begin{tightcenter}
    \ce{2SO2 + V2O5 -> 2SO3 + V2O3}\\
    \ce{V2O3 + O2 -> V2O5}
\end{tightcenter}
随后一般被通入$98.3\%$硫酸中吸收,这就是工业制硫酸的方法.

\subsection{硫的含氧酸}
\subsubsection{亚硫酸~\ce{H2SO3}和焦亚硫酸~\ce{H2S2O5}}
亚硫酸~\ce{H2SO3}和焦亚硫酸~\ce{H2S2O5}难以作为纯物质被单独分离,而仅存在于~\ce{SO2}的水溶液中.含有亚硫酸根阴离子~\ce{SO3^{2-}}或焦亚硫酸根阴离子~\ce{S2O5^{2-}}的盐则被广泛应用.
\paragraph{阴离子的结构}
亚硫酸根离子~\ce{SO3^{2-}}具有典型的三角锥结构,与经典理论预测一致.亚硫酸氢根离子~\ce{HSO3-}有两种互变异构体.占主要的那种是具有$C_{3\text v}$对称性的\ce{HSO3-}而非\ce{HOSO2^-}.~\ce{S2O5^2-}的结构也不同寻常,其中的两个~\ce{S}原子并不等价,而是由一根长而弱的~\ce{S-S}键相连.

\paragraph{阴离子的性质与反应}
\ce{HSO3-}和~\ce{SO3^2-}为中等强度的还原剂.它们与~\ce{I2}能发生定量的反应(这一反应在Karl Fischer法滴定微量水时被用到):
\begin{tightcenter}
    \ce{HSO3- + I2 + H2O <=> HSO4- + 2H+ + 2I-}
\end{tightcenter}
在强还原剂的存在下,它也能被还原,但还原产物与使用的还原剂有关:
\begin{tightcenter}
    \ce{2SO3^2- + 2H2O + 2Na(Hg) -> S2O4^2- + 4OH- + 2Na+}\\
    \ce{2SO3^2- + 4HCOO- -> S2O3^2- + 2C2O4^2- + 2OH^- + H2O}
\end{tightcenter}\ce{S2O5^2-}的盐可以容易地由亚硫酸氢盐浓缩制得:
\begin{tightcenter}
    \ce{2HSO3^- <=> S2O5^2- + H2O}
\end{tightcenter}
\indent 焦亚硫酸盐的一个重要应用是添加到葡萄酒原浆中以杀死微生物,其原理是~\ce{S2O5^2-}在水中分解为~\ce{SO2}分子并起到杀菌作用:
\begin{tightcenter}
    \ce{S2O5^{2-} + 2H+ <=> 2SO2 + H2O}
\end{tightcenter}
\subsubsection{硫酸~\ce{H2SO4}}
硫酸是硫的含氧酸中最重要的一种,化学式为~\ce{H2SO4}.由于稀硫酸的性质主要体现为~\ce{SO4^{2-}}和~\ce{H+}的性质,并且前者在通常的反应条件下是稳定的,因此本节的重心将放在无水硫酸和浓硫酸的性质上.
\paragraph{硫酸的结构}
无水硫酸为无色粘稠的液体,与水以任意比例混溶,混合过程放出大量的热.无水硫酸的高粘度来源于其中存在的氢键网络.在固体中,相邻的~\ce{H2SO4}分子之间通过氢键形成三维网状结构:
\begin{figure}[H]\centering
    \includegraphics[scale=0.125]{figure/H2SO4.png}
    \caption{\ce{H2SO4}的晶体结构\quad$\text{C}\,2/\text{c}$\quad$a=\SI{818.1}{\pico\meter},b=\SI{469.6}{\pico\meter},\,c=\SI{856.3}{\pico\meter},\,\beta=111.4^\circ$}
\end{figure}
\paragraph{硫酸作为无水溶剂}
在无水硫酸中存在一系列平衡:
\begin{tightcenter}
    \ce{2H2SO4 <=> H3SO4+ + HSO4-}\\
    \ce{2H2SO4 <=> H3O+ + HS2O7-}\\
    \ce{H3O+ + HSO4- <=> H2SO4 + H2O}\\
    \ce{HS2O7- + H3SO4+ <=> H2S2O7 + H2SO4}\\
    \ce{H2S2O7 <=> H2SO4 + SO3}
\end{tightcenter}
因此,无水硫酸中事实上至少含有七种组分.这也经常被用于考察平衡计算.无水硫酸的许多性质也是因为存在这些物种.同时,无水硫酸中存在由~\ce{H3SO4+}和~\ce{HSO4-}构成的氢键传递网络,因此电导率也非常高(类似~\ce{H2O}中存在的氢键网络).\\
\indent 大多数物质在无水~\ce{H2SO4}中都作为碱存在,其中最典型的例子就是~\ce{H2O}.因此如果某一反应在浓硫酸体系生成~\ce{H2O},那么最好将其写作~\ce{H3OHSO4}或~\ce{H2O.nH2SO4}的形式.少数更强的酸,例如~\ce{H2S2O7},~\ce{HSO3F}等可以作为酸将~\ce{H2SO4}质子化.一个特殊的例子是硼酸溶于无水硫酸形成的四硫酸氢硼酸:
\begin{tightcenter}
    \ce{H3BO3 + 3H2S2O7 -> H3SO4+ + [B(HSO4)4]- + H2SO4}
\end{tightcenter}
\ce{H[B(HSO4)4]}是比~\ce{HSO3F}酸性更强的酸,但是目前没有分离出游离的~\ce{H[B(HSO4)4]}.在某些情况下,在硫酸溶液中形成的阳离子并不稳定而发生分解:
\begin{tightcenter}
    \ce{H2C2O4 + H2SO4 -> CO + CO2 + [H3O]+ + [HSO4]-}
\end{tightcenter}
\indent 由于自耦电离为~\ce{[H3O]+}和~\ce{[HS2O7]-}的反应,对浓硫酸直接进行质子化并不能将其完全转化为~\ce{[H3SO4]+}.一种制备它的好方法是利用~\ce{Si-F}键的高稳定性,用~\ce{HF/SbF5}体系处理硫酸硅醇酯:
\begin{tightcenter}
    \ce{(Me3SiO)SO2 + 3HF + SbF5 ->[HF] [H3SO4]+[SbF6]- + 2Me3SiF}
\end{tightcenter}
这种方法也被用于制备~\ce{H2O2},~\ce{H2CO3}等不易质子化的物质\cite{Minkwitz1998}\cite{Minkwitz1999}.
\subsubsection{过一硫酸~\ce{H2SO5}与过二硫酸~\ce{H2S2O8}}
无水过一硫酸~\ce{H2SO5}(亦被称作Caro酸)可由无水过氧化氢和氯磺酸反应值得,然而此物质少有用处,主要作为电解法制备~\ce{H2S2O8}及其盐的副产物而出现.\\
\indent 过二硫酸~\ce{H2S2O8}为无色固体,可以以任意比例混溶于水中;熔点为$\SI{65}{\celsius}$,熔化时分解.~\ce{(NH4)2S2O8}和~\ce{K2S2O8}是过二硫酸的两种最重要的盐,它们都易溶于水(但~\ce{K2S2O8}溶解得十分缓慢).这些盐比酸更容易制备,它们都已实现工业化生产,其法是由相应的硫酸盐进行阳极氧化.\\
\indent 过二硫酸及其盐常被用作强氧化剂.除去少数物质,例如~\ce{F2},~\ce{H2N2O2},~\ce{O}和~\ce{OH}等,电对$\ce{S2O8^2-}/\ce{HSO4-}$的电极电势比其它水溶液中的电对都要高.然而,过二硫酸作为氧化剂的反应速率是较慢的.由于~\ce{-SO3}的位阻因素,还原剂的电子直接进入~\ce{O-O}键的$\sigma^\ast$轨道较为困难;因此主要起到作用的氧化剂是其均裂产生的~\ce{SO4^{-}}自由基阴离子,后者由于~\ce{-SO3}的强吸电子作用不稳定,所以这一步的活化能是很高的.通常,氧化反应需要可变价的离子参与催化,总体机理如下所示:
\begin{tightcenter}
    \ce{S2O8^{2-} + M^{n+} -> SO4^{2-} + SO4-+ M^{(n+1)+}}\\
    \ce{SO4^{-} + M^{n+} -> SO4^{2-} + M^{(n+1)+}}
\end{tightcenter}
通常加入~\ce{Ag+}作为催化剂(中间体是~\ce{Ag^{2+}}离子),因为~\ce{Ag^{II}}也具有很强的氧化性.
\subsubsection{硫代硫酸~\ce{H2S2O3}}
硫代硫酸~\ce{H2S2O3}也是硫的含氧酸中比较重要的一种.正如其名,~\ce{S2O3^2-}的结构可以看作由~\ce{SO4^2-}衍生而来,只是把其中一个端基~\ce{O}替换为~\ce{S}.\\
\indent 硫代硫酸可以在无水低温条件下通过下面的反应制备得到:
\begin{tightcenter}
    \ce{H2S + HSO3Cl -> H2S2O3 + HCl}
\end{tightcenter}
游离的硫代硫酸遇水即发生迅速而复杂的分解,这也是碘量法需要控制溶液pH在近中性的原因.一种典型的分解方式为
\begin{tightcenter}
    \ce{H2S2O3 -> H2S + SO3}
\end{tightcenter}
硫代硫酸盐则相对稳定得多,可以由~\ce{HS^-}与~\ce{HSO3^-}反应制得:
\begin{tightcenter}
    \ce{2HS- + 4HSO3- -> 3S2O3^2- + 3H2O}
\end{tightcenter}
也可以由~\ce{SO3^2-}与硫单质的反应制得:
\begin{tightcenter}
    \ce{8Na2SO3 + S8 -> 8Na2S2O3}
\end{tightcenter}
\indent 硫代硫酸盐的用途远比硫代硫酸主要.\tbf{海波}(也称作\tbf{大苏打}),即五水合硫代硫酸钠,化学式为~\ce{Na2S2O3.5H2O},是一种无色晶体,熔点$\SI{48.5}{\celsius}$,易溶于水.海波在照相业中用作定影剂,用于溶解未反应的~\ce{AgBr},反应的方程式为
\begin{tightcenter}
    \ce{AgBr + 3S2O3^2- -> [Ag(S2O3)3]^5- + Br-}
\end{tightcenter}
在数码摄影飞速发展的今日,已经很少有人使用这种传统方法摄影了.需要注意,~\ce{Ag(S2O3)2^{5-}}中每个~\ce{S2O3^{2-}}只有端基的~\ce{S}原子参与对~\ce{Ag+}的配位,其结构为典型的~\ce{Ag^{I}}配合物的直线型.\\
\indent 硫代硫酸钠是一种中等强度的还原剂.~\ce{S2O3^2-}与~\ce{I2}定量地发生反应,这是碘量法的理论基础:
\begin{tightcenter}
    \ce{2S2O3^2- + I2 -> S4O6^2- + 2I-}
\end{tightcenter}
更强的氧化剂可以将其直接氧化为~\ce{S^{VI}}:
\begin{tightcenter}
    \ce{S2O3^2- + 4Cl2 + 5H2O -> 2HSO4- + 8H+ + 8Cl-}
\end{tightcenter}
\ce{Br2}的氧化性介于~\ce{I2}和~\ce{Cl2}之间,根据不同条件,~\ce{S2O3^2-}可作为单电子或八电子还原剂.如果你将~\ce{S2O3^2-}用~\ce{Br2}的浓溶液进行滴定,然后将两种溶液各稀释$100$倍再进行滴定,会发现~\ce{S2O3^2-}的滴定度正好变为$8$倍.
\subsubsection{连二硫酸~\ce{H2S2O6}和连多硫酸~\ce{H2S_nO6}}
纯的连二硫酸和连多硫酸都没有制得.连二硫酸在水溶液中是一种中强酸,其阴离子~\ce{[S2O6]^2-}具有较长的~\ce{S-S}键,容易按照下面的反应发生分解:
\begin{tightcenter}
    \ce{[S2O6]^2- ->[H+] SO2 + [SO4]^2-}
\end{tightcenter}
而~\ce{[S2O6]^2-}本身和~\ce{[SO4]^2-}有一定的相似性,不容易参与溶液中的氧化还原反应.\\
\indent 连二硫酸盐通常可由亚硫酸盐进行氧化制得,例如由水合~\ce{MnO2}或~\ce{Fe2O3}的悬浊液对~\ce{SO2}的水溶液进行氧化即得相应的连二硫酸盐:
\begin{tightcenter}
    \ce{2MnO2 + 3SO2 ->T[aq,$\SI{0}{\celsius}$] MnSO4 + MnS2O6}\\
    \ce{Fe2O3 + 3SO2 ->T[aq,$\SI{0}{\celsius}$] FeSO3 + FeS2O6}
\end{tightcenter}
然后通过复分解反应即可制备其它连二硫酸盐.\\
\indent 对连多硫酸及其盐的研究具有悠久的历史. 1808年, John Dalton发现~\ce{H2S}与~\ce{SO2}作用得到的水溶液中含有各种连硫酸. 1846年, H.W.F.Wackenroder对这类溶液又进行了系统的研究,因此该体系以他的名字命名为\tbf{Wackenroder溶液}.除了这种方法之外,各种连多硫酸盐还可以通过以下方法制备:
\begin{tightcenter}
    \ce{2Na2S2O3 + 4H2O2 -> Na2S3O6 + Na2SO4 + 4H2O}\\
    \ce{2Na2S2O3 + I2 -> Na2S4O6 + 2NaI}\\
    \ce{SCl2 + 2[HSO3]- -> [S3O6]^{2-} + 2HCl}\\
    \ce{S2Cl2 + 2[HSO3]- -> [S4O6]^{2-} + 2HCl}
\end{tightcenter}
\subsubsection{连二亚硫酸~\ce{H2S2O4}}
纯的连二亚硫酸也尚未制备得到.连二亚硫酸盐可以通过用~\ce{Zn}或~\ce{Na}汞齐还原~\ce{[SO3]2-}的水溶液得到:
\begin{tightcenter}
    \ce{2Na2SO3 + 2H2O + 2Na(Hg) -> 4NaOH + Na2S2O4}
\end{tightcenter}
连二亚硫酸盐在工业上广泛用作还原剂;它还可以还原各种重金属离子.这类反应较多地被用于净化污水.\\
\indent 连二亚硫酸的无水盐是稳定的,但在水溶液中酸性条件下或强碱性条件下将发生分解:
\begin{tightcenter}
    \ce{2S2O4^2- + H2O -> S2O3^2- + 2HSO3^-}\\
    \ce{3S2O4^2- + 6OH^- -> 5SO3^2- + S^2- + 3H2O}
\end{tightcenter}
连二亚硫酸盐加热时也将发生分解,分解方式和酸性条件下的歧化类似:
\begin{tightcenter}
    \ce{2Na2S2O4 ->T[$\Delta$] Na2S2O3 + Na2SO3 + SO2}
\end{tightcenter}
\indent \ce{S2O4^2-}具有明显的重叠式结构,并且~\ce{S-S}键明显偏长:
\begin{figure}[H]\centering
    \includegraphics{figure/[S2O4]2-.eps}
    \caption{\ce{S2O4^2-}的立体结构示意图}
\end{figure}
较长的~\ce{S-S}键说明其较弱而容易发生断裂.光谱分析表明~\ce{S2O4^2-}的水溶液中也有少量~\ce{SO2^{$\cdot$-}}存在:
\begin{tightcenter}
    \ce{S2O4^2- <=> 2SO2^{$\cdot$-}}
\end{tightcenter}
\subsubsection{次硫酸~\ce{H2SO2}}
次硫酸盐~\ce{H2SO2}极不稳定,只能以盐的形式存在.用锌作用于~\ce{SO2Cl2}的乙醚溶液,可制得次硫酸锌:
\begin{tightcenter}
    \ce{2Zn + SO2Cl2 -> ZnSO2 + ZnCl2}
\end{tightcenter}
将~\ce{Co(OAc)2}与~\ce{Na2S2O4}溶液反应,然后加入过量的~\ce{NH3},即可得到棕色的次硫酸钴晶体:
\begin{tightcenter}
    \ce{Co(OAc)2 + Na2S2O4 -> CoS2O4 + 2NaOAc}\\
    \ce{CoS2O4 + 2NH3 + H2O -> CoSO2 + (NH4)2SO3}
\end{tightcenter}
甲醛次硫酸氢钠~\ce{NaHSO2.CH2O.2H2O}就是俗称的\tbf{雕白粉},具有很强的还原性,例如可以将~\ce{I2}还原为~\ce{I-}:
\begin{tightcenter}
    \ce{NaHSO2.CH2O.2H2O + 2I2 -> 4HI + NaHSO4 + CH2O}
\end{tightcenter}
甲醛次硫酸氢钠在印染工业中常用作拔染剂,在制糖工业中则常作为漂白剂.

\paragraph{\ce{S2F2}}

\paragraph{\ce{SF2}}
\ce{SF2}的稳定性并不如与它相似的~\ce{H2S}或~\ce{SCl2},因而难以得到.这种化合物需要~\ce{KF}对~\ce{SCl2}氟化后的一系列硫的氟化物中分离制得.
\paragraph{\ce{SF4}}

\begin{tightcenter}

\end{tightcenter}
它具有经典的跷跷板结构,其中的四个~\ce{F}是不断流变的.有关~\ce{SF4}的有趣的衍生结构是~\ce{(H2C)SF4},它和~\ce{SOF4}一样具有三角双锥结构,轴向的~\ce{F}向远离端基~\ce{O}或~\ce{CH2}的方向偏移.值得注意的是~\ce{CH2}中的两个~\ce{H}与轴向~\ce{F}共平面而不是在赤道平面上\cite{Oberhammer1979}.我们可以简单地认为~\ce{S}原子的$\text{p}_z$轨道用于与轴向的~\ce{F}原子成键,因而不能形成$\pi$键.于是~\ce{S=C}$\pi$键只能垂直于$xy$平面(即赤道平面),因而~\ce{CH2}基团只能位于轴向平面上.

\paragraph{\ce{SF6}与\ce{S2F10}}
六氟化硫~\ce{SF6}可由硫在氟气氛中燃烧制得.它是无色,无臭,无味,无毒的气体\footnote{少量吸入~\ce{SF6}可以让声音变得粗犷,这和吸入~\ce{He}使得声音变细正好相反.请勿自行尝试此实验,以避免窒息风险.},无反应性和可燃性,也无溶解性.正由于它突出的稳定性和优良的绝缘性,广泛用作高压发电机和开关装置中的绝缘气体.\\
\indent 近年来的最新观点认为~\ce{SF6}中的~\ce{S}并非VSEPR理论所认为的$\text{d}^2\text{sp}^3$杂化,而是采取sp杂化与两个~\ce{F}成键,其余四个~\ce{F}则与~\ce{S}通过电性作用结合.经过平均化后,形成了正八面体的~\ce{SF6}分子.\\
\indent 对硫的不完全氟化可以得到~\ce{S2F10}分子.它的结构可以看作是两个~\ce{SF6}各自去掉一个~\ce{F}后两个~\ce{S}相连的结果.由于没有特别的轨道作用,为了避免位阻,~\ce{S2F10}采取交错式结构,其中的~\ce{S-S}键也较长且弱.\\
\indent \ce{S2F10}的反应性介于~\ce{SF4}与~\ce{SF6}之间.它不为水所水解,甚至不为稀酸或稀碱所水解,这一点和~\ce{SF4}不同;它作为剧毒物质也不同于~\ce{SF6}.~\ce{S2F10}在$\SI{15}{\celsius}$时迅速发生歧化,分解生成~\ce{SF4}和~\ce{SF6}.\\
\indent \ce{S2F10}可以在丙酮溶液中氧化~\ce{KI}而析出~\ce{I2}.还原产生的~\ce{SF4}还可以对丙酮进行氟化,因此反应的方程式应当为:
\begin{tightcenter}
    \ce{S2F10 + 2KI + 4Me2CO -> 2SO2 + 2KF + I2 + 4Me2CF2}
\end{tightcenter}

\subsubsection{硫的氯化物}
在剩余的硫的卤化物中,我们主要讨论最常见的~\ce{SCl2}和~\ce{S2Cl2},它们都是重要的化工产品.
二氯化硫~\ce{SCl2}是有毒且有恶臭味的樱桃红色液体,易挥发,熔点为$\SI{-122}{\celsius}$,沸点为$\SI{59}{\celsius}$.二氯化二硫~\ce{S2Cl2}是有毒且有恶臭味的金黄色液体,熔点为$\SI{-76}{\celsius}$,沸点为$\SI{138}{\celsius}$.\\
\ce{S2Cl2}在热力学上比~\ce{SCl2}更稳定.因此,如果某一反应应当生成硫的氯化物,在没有其它提示的情况下你可以优先考虑~\ce{S2Cl2}的生成.~\ce{SCl2}最著名的反应是对乙烯的硫代氯化:
\begin{tightcenter}
    \ce{SCl2 + C2H4 -> S(CH2CH2Cl)2}
\end{tightcenter}
产物即臭名昭著的芥子气.在人体中,芥子气可以发生分子内$\text{S}_{\text{N}}2$反应生成具有很强亲电性的硫代环丙烷正离子,容易将DNA等物质烷基化而破坏其生命活性;相比一般的烷基化试剂,芥子气有两个烷基化位点,可以将DNA交联而扭曲双螺旋结构,进而阻碍DNA复制时正常解旋\cite{Dacre1996}.
\subsubsection{硫的氯氧化物}
硫可以形成两个主要系列的卤氧化物,即~\ce{S^{IV}OX2}和~\ce{S^{VI}O2X2}.我们主要介绍亚硫酰氯~\ce{SOCl2}和硫酰氯~\ce{SO2Cl2}.
亚硫酰氯~\ce{SOCl2}是无色易挥发的液体,熔点为$\SI{-101}{\celsius}$,沸点为$\SI{76}{\celsius}$.硫酰氯~\ce{SO2Cl2}也是无色易挥发的液体,熔点为$\SI{-54}{\celsius}$,沸点为$\SI{69}{\celsius}$.\indent \ce{SOCl2}可以由~\ce{SO2}氯化得到,亦可以由~\ce{SCl2}被~\ce{SO3}氧化得到:
\begin{tightcenter}
    \ce{SO2 + PCl5 -> SOCl2 + POCl3}\\
    \ce{SCl2 + SO3 -> SOCl2 + SO2}
\end{tightcenter}
\ce{SOCl2}能与~\ce{H2O}剧烈作用,,可以对容易水解的无机卤化物进行脱水.以~\ce{FeCl3.6H2O}为例:
\begin{tightcenter}
    \ce{FeCl3.6H2O + 6SOCl2 -> FeCl3 + 6SO2 + 12HCl}
\end{tightcenter}
与DMSO一样,~\ce{SOCl2}也可以作为溶剂使用.\\
\indent 工业上用活性炭或~\ce{FeCl3}为催化剂,将~\ce{SO2}直接氯化就可以得到~\ce{SO2Cl2}.这也是一种有用的氯化试剂.

\subsubsection{二元硫氮化合物}
硫氮化合物和氮氧化合物在结构上并无多大相似之处.大部分硫氮化合物都是较大的分子,其中最重要的是~\ce{S4N4}.这是一种橙黄色的晶体,在空气中可以稳定存在,但受到撞击或迅速加热时会发生爆炸.它可以通过下面几种方法制备:
\begin{tightcenter}
    \ce{6S2Cl2 + 16 NH3 ->T[$80\tccentigrade$] S4N4 + 8S + 12NH4Cl}\\
    \ce{6SCl2 + 16 NH3 -> S4N4 + 2S + 12NH4Cl}\\
    \ce{6S2Cl2 + 4NH4Cl ->T[$160\tccentigrade$] S4N4 + 8S + 16HCl}
\end{tightcenter}
\indent\ce{S4N4}具有不同寻常的环状结构,其分子点群为$D_{2\text{d}}$,~\ce{N}原子位于同一平面上,$S$原子分居平面两侧(注意与同为八元环状结构的~\ce{S8}分子的结构区别).
