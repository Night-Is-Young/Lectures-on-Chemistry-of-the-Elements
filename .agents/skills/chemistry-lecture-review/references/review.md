# 核查规则与项目实例

## 科学核查

- 方程式：区分总反应、半反应、机理示意、通式、平衡和核反应。检查原子与电荷及必要的电子、介质、物相；配平通过不代表真实可行，机理步骤不能仅凭总反应反推。
- 物种：化学式、氧化态、部分电荷、自由基电子数、配位数与结构一致；区分分子内键和次级接触、孤立分子与晶体聚合结构。
- 数据：温压、物相、溶剂、离子强度、标准态、实验或计算来源影响比较时应明确。排查摄氏与开尔文、能量与波长、每摩尔反应与每摩尔物质的混淆。
- 推导：检查符号、等号、边界条件、变量定义、量纲、近似与数值。独立复算影响结论的步骤；平衡常数涉及分压时注意标准压力和无量纲形式。
- 成键解释：区分构型预测、定性轨道模型与实验支持；群论允许的耦合不独自证明唯一畸变方向。反应快慢不能由电势或反应焓单独推出。
- 来源：已有引用只表示作者引用过，不证明邻近的每一句都被支持。核对实际文献的页码／图表、物种及条件。区分实验合成、检测、计算预测、历史归属和作者解释。
- 时间性：“首次”“唯一”“尚未制得”“目前已知”等需要查后续研究和时间范围；缺少证据时列待核查，不能凭记忆给出更新结论。
- 正文与习题：物种名称、温度压力、数据和定义相互对照。不同条件不自动等于矛盾；判断是否足以改变答案。扩展题可超出正文，但需给足信息。
- 图表：正文、图题、文件名和真实图像相互核对。晶系／空间群／晶胞参数、图的视向、轨道相位与占据需相容。未查看图像时不能声称图本身正确。

涉及健康处置、毒性定量、现行规范等高风险或时效内容时使用可靠的当前来源，不将泛化的教材叙述直接升级为操作或治疗建议。

## 证据记录

为每个实质问题记录“位置—论断—来源—实际阅读范围—条件—结论”。优先使用本地现有文献及原始研究；综述帮助找到来源。来源不可访问或只读到摘要时，明确限制。不虚构 DOI、引用键、页码和参考文献内容。

可能的表述：

- 文内可确定：该式两侧的硫原子数不相等，说明式子有误；结合所在小节提出具体改法。
- 外部来源支持：给出来源支持的物种及限定条件，解释原文何处扩大了结论。
- 待核查：当前因果链不足，但尚不能判定哪个词或数值写错，列出应回查的证据。
- 教学建议：内容本身可以成立，只是缺少先修说明或图文衔接；不要包装成科学错误。

## 阅读时发现的验收案例

以下路径均相对讲义根目录。行号会变化，按原文关键词定位。案例来自 2026-09-13 源码阅读；不是一份已完成的全面文献审计。修订后应读取新正文，不能重复报告旧问题。

1. `Chapter 2 p区元素/VIA/S.tex`，H2S 制备：`FeS + 2HCl -> FeCl2 + H2O`。由元素守恒可确定式子有误，结合主题可定位产物疑似误写。验收：既发现问题，也不把配平当成实验核验。
2. `Chapter 2 p区元素/VIIA/VIIA.tex`，HF 酸性：`ln K_a(T)=-(-Delta G_r)/(RT)` 与后面的熵焓展开式不一致。验收：指出等式不自洽，核对标准态记号及相邻数值。
3. `Chapter 2 p区元素/0/0.tex`，Xe3O2 图后的 Xe2O5 名称与 `+4:0=1:2` 描述。验收：识别化学式／价态／图题不一致，再定位应修改哪一处，不机械改掉所有 Xe2O5。
4. `Chapter 2 p区元素/VIA/Se,Te.tex`，“二卤化物”之下出现“四氟化物”段标题，但内容在介绍 SeCl2、SeBr2。验收：识别标题复制残留。
5. `Chapter 2 p区元素/VIIA/VIIA.tex`，“应用”“原子性质”“卤键参与的低聚物”为空；但 `S.tex` 多原子阳离子明确转至 `Se,Te.tex`。验收：前者为候选增补，后者为有意安排，不重复补写。
6. `Chapter 2 p区元素/0/0.tex`，Na2He 正文与题目给出不同压力。验收：先核查合成条件和理论稳定阈值是否被混淆，不能只挑一个数统一。
7. 同文件中“继续向 XeF5- 添加 F- 是放热的，因此目前并没有得到……” 。验收：标出论证不足并回查来源，不未经证据把“放热”改成“吸热”。
